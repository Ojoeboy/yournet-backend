Fix signup TDZ bug, duplicate-email accounts, and /login mislabeling

1. src/routes/auth.js - /signup threw a ReferenceError on every attempt:
   licenseKey (the key string from the request body) was shadowed by a
   later 'const licenseKey' (the DB row) declared in the same block,
   triggering the temporal dead zone. Renamed the row variable to
   licenseKeyRow. Also added a check for an existing account by email,
   returning a clear error instead of silently allowing duplicates.

2. src/db/schema.sql - owner_email TEXT UNIQUE NOT NULL was declared
   only inside CREATE TABLE IF NOT EXISTS tenants, so on a database
   where tenants already existed, that constraint never actually took
   effect (same bug class as the earlier sites.active fix). Added a
   non-destructive migration step: for any owner_email shared by more
   than one tenant, the oldest row keeps its email, newer duplicates
   get tagged +dupN@duplicate.local (no data deleted), then creates
   the unique index that should have existed from the start.

3. public/login.html - was mislabeled 'Agent Portal', copied by
   mistake from the styling reference screenshot of the separate
   agent.html page. Now correctly reads 'YourNet Control'.
