Add live dropdown for Mikrotik hotspot profile in Router setup

Previously the "Hotspot profile" field in Setup > 1. Router was a
plain text input pre-filled with "default" - not connected to the
router in any way, so a typo or a profile that doesn't actually
exist would go unnoticed until a voucher redemption failed.

- mikrotik.js: new listHotspotProfiles() - connects and runs
  /ip/hotspot/profile/print, returns the profile names that
  actually exist on the router
- sites.js: new POST /api/sites/mikrotik/hotspot-profiles - unlike
  the existing /:id/test route, this works with credentials typed
  into the form directly, since the site isn't saved yet at this
  point in setup
- admin.html: mkProfile is now a <select> with a "Fetch from
  router" button that calls the new endpoint using whatever
  host/port/username/password/TLS are currently filled in, and
  populates the dropdown with the real results
