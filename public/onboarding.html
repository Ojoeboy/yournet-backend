Get set up

Six quick steps from a new account to your first printable vouchers. You can leave any step's optional fields blank and adjust them later in the full admin panel.

1. Add your first site

A "site" is one router/location. You can add more later.

2. Router configuration

If your MikroTik router isn't configured for this yet, generate a ready-to-import config file. Already configured? Skip this.

3. Branding your customers see

Shown on the WiFi login page and printed vouchers. You can fine-tune this later in Admin → Portal.

4. Create a package

A price + duration combo customers buy. Start with one — add more later in Admin → Packages.

5. Generate your first vouchers

6. You're set up

Your site, portal branding, first package, and vouchers are all live. From here, everything is managed from the full admin panel.
