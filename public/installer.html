RADIUS setup

Enter these into the router's RADIUS client config:

Server address-
Auth port-
Accounting port-
NAS-Identifier-
Secret-

On RouterOS: /radius add service=hotspot address=<server address> secret=<secret> nas-identifier=<NAS-Identifier> authentication-port=<auth port> accounting-port=<accounting port>, then /ip hotspot profile set [find] use-radius=yes.
